# Cue preferences

Checked 2026-10-27. A: Apple and repository implementation. Recommendation: host-app sections inside the existing Settings module, with four app-owned non-secret keys for sound, countdown, voice and haptics. `SettingsView` accepts `@ViewBuilder extra` between Appearance and About; `StarterSettingsView` demonstrates it. Register defaults at every launch: the registration domain is volatile and falls back behind stored values ([Apple, A](https://developer.apple.com/documentation/foundation/userdefaults/register(defaults:))). Keep `@AppStorage` defaults and registered values consistent, test absent and explicitly false values, and inject a separate defaults suite in tests. Define how countdown depends on sound without silently rewriting the user's preference. Keep secrets in Settings' Keychain abstraction. `@AppStorage` and this design support iOS 17.
