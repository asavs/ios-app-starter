# Keeping the run screen awake

Checked 2026-10-27. A: Apple. Recommendation: app-specific lifecycle policy. Set `UIApplication.shared.isIdleTimerDisabled` only during an active, visible run when the person benefits, then clear it on pause, exit, scene inactivity and interruption as appropriate. The property is app-wide, so centralize ownership and account for multiple scenes or overlapping users of the setting; avoid an unconditional cleanup that cancels another owner's request. Apple's documentation warns to disable the idle timer only when necessary because of power cost ([Apple, A](https://developer.apple.com/documentation/uikit/uiapplication/isidletimerdisabled)). Verify lock behavior and restoration on a physical device. This does not prevent manual locking or grant background execution. Available on iOS 17.
