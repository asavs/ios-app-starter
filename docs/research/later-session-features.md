# Later session features

Checked 2026-10-27. A: Apple. A Live Activity may show a running interval on the Lock Screen and Dynamic Island, using a deadline rather than frequent app wakeups. ActivityKit lifecycle, authorization, stale state and maximum duration require separate design and device tests ([Apple, A](https://developer.apple.com/documentation/activitykit)). It does not guarantee background cue execution. Session history is app-owned structured data: record completed or interrupted sessions only with an explicit retention and privacy policy, and migrate it with the database plan. Both are candidates for optional modules: a session display adapter and a persistence pattern, with host-owned content and retention policy. Live Activities are available by iOS 17; AlarmKit is iOS 26+.

A session display adapter could accept immutable phase, deadline and localized label snapshots from SessionClock, while a history scaffold accepts host-owned persistence models. A workout, focus timer or meditation app could use either; both remain optional and should not pull Settings or Theme into the clock engine. Demo a Live Activity countdown and a local session list, including explicit end and interrupted state. ActivityKit authorization and update limits need separate research and physical-device checks; do not infer that a display updates app code while suspended.
