# Progress ring

Checked 2026-10-27. A: Apple; B: developer tutorial. Recommendation: propose an optional reusable TimerRing view, usable by interval workouts, Pomodoro sessions and meditation.

A foreground `Circle` trimmed to a clamped 0...1 fraction, stroked with round caps over a background circle, is a common approach ([Cindori, B](https://cindori.com/developer/swiftui-animation-rings)). Rotate the start to the top if desired; round caps visually extend short arcs, and zero/complete states need explicit inspection. Apple's circular `ProgressView` can be indeterminate where a determinate circular style is unavailable ([Apple, A](https://developer.apple.com/documentation/swiftui/progressviewstyle/circular)).

Derive the fraction from the session clock, not animation completion. Smooth linear interpolation can look continuous but must be corrected after pause, phase change or resume; stepped updates reduce motion and work. Honor `accessibilityReduceMotion` and avoid unnecessary animation ([Apple, A](https://developer.apple.com/documentation/swiftui/accessible-appearance)). Expose one meaningful accessibility element with phase and localized remaining duration, not color alone or a stream of announcements every 50 ms. Announce phase transitions sparingly; check VoiceOver focus and Dynamic Type on device. Test color contrast and zero/short durations. APIs used here are available on iOS 17.

## Proposed module

A workout, Pomodoro or meditation app can supply the same indicator with different phase labels and colors. Proposed conceptual API: `TimerRing(fractionRemaining: Double, phaseLabel: Text, remaining: Duration, style: TimerRingStyle)`. The host supplies a clamped snapshot and localized duration; the ring never owns a clock or fires cues. Style includes track, progress color, stroke width, cap and size; semantic phase text remains independent of color. A `TimerRingStyle` can read Theme tokens at the host boundary while the core component remains usable without Theme. Demo running, paused, zero and multiple phases, plus large text and Reduce Motion previews. Apple's [Activity rings HIG](https://developer.apple.com/design/human-interface-guidelines/activity-rings) (A, checked 2026-10-27) reserves Activity rings for Move, Exercise and Stand and says not to replicate or modify them for other purposes. Use a single timer ring with its own styling; do not imitate the concentric Activity rings or their colors.

Expose a single accessibility element such as "Rest, 45 seconds remaining" with a localized label and value, hiding decorative circles and duplicated text. Do not repeatedly post announcements from rendering. Test VoiceOver, color contrast, Dynamic Type, zero-duration and near-complete cap overlap. Animation should interpolate a value without creating its own timeline; when phase or pause changes, update from the current clock snapshot. Apple's [accessibility descriptions](https://developer.apple.com/documentation/swiftui/accessible-descriptions) and [Reduce Motion setting](https://developer.apple.com/documentation/swiftui/accessible-appearance) are primary guidance (A). [Text timer intervals](https://developer.apple.com/documentation/swiftui/text/init%28timerinterval%3Apausetime%3Acountsdown%3Ashowshours%3A%29) are an alternative for a date-based countdown label (A), but do not replace session state.

## Implementations worth reading

| Project | Use and assessment | License |
| --- | --- | --- |
| [UICircularProgressRing](https://github.com/luispadron/UICircularProgressRing) | SwiftUI progress and timer components with rich API; archived in 2022, so useful prior art rather than a fresh dependency recommendation. | MIT, B |
| [PZCircularControl](https://github.com/philptr/PZCircularControl) | Styleable indicator or editable control with animation; its breadth is useful to compare, but the timer module should remain a read-only indicator unless interaction is needed. | MIT, B |
| [ProgressUI](https://github.com/mumer92/progressui) | Circular and linear styles, direction and cap choices. Verify accessibility and behavior before reuse; README is not evidence of device testing. | MIT, B |
| [circular-progress](https://github.com/aleksproger/circular-progress) | SwiftUI styles with a content builder; useful reference for host-owned labels. Verify its actual release and maintenance before adopting. | MIT, B |

Apple's [Scrumdinger drawing tutorial](https://developer.apple.com/tutorials/app-dev-training/drawing-the-timer-view) (A, checked 2026-10-27) builds a SwiftUI `Shape` with arc segments for meeting progress, a first-party example of an arc-based timer view. [Cindori's trim-and-stroke walkthrough](https://cindori.com/developer/swiftui-animation-rings) (B) illustrates ring mechanics. Apple's [circular ProgressView style](https://developer.apple.com/documentation/swiftui/progressviewstyle/circular) (A) warns that determinate circular presentation may not be available in every context; check the native control before adding custom drawing. [WWDC21 TimelineView](https://developer.apple.com/videos/play/wwdc2021/10018/) (A) demonstrates render schedules, not a background timer guarantee. No library has been built, performance-tested or audited for accessibility here.
