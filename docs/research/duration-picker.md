# Duration picker

Checked 2026-10-27. A: Apple. Recommendation: propose an optional duration picker component for timers, workouts and cooking apps, starting with two labeled native SwiftUI wheel pickers backed by one validated duration; use a Stepper for bounded small ranges if it better fits the workflow. `UIDatePicker` countdown mode displays hours and minutes, not seconds, even though its value is measured in seconds ([Apple, A](https://developer.apple.com/documentation/uikit/uidatepicker/countdownduration)). SwiftUI's date picker represents dates, so do not model an interval as a date merely for convenience. Define minimum, maximum and zero behavior and handle carry, localization, plural units and Dynamic Type. Expose distinct accessible labels and values, test VoiceOver adjustment and touch targets on iPhone and iPad. Native picker and Stepper APIs support iOS 17. Extract a reusable picker only after another app needs the same range and interaction.

The Maestro project reports that some wheel picker styles expose incomplete accessibility hierarchies, so test actual picker-wheel queries rather than assuming modifier placement ([Maestro, B](https://docs.maestro.dev/get-started/supported-platform/ios/swiftui)). This is a tool-specific report, not a general SwiftUI contract.

## Module shape

`DurationPickerRow(value: Binding<Duration>, range: ClosedRange<Duration>, step: Duration, label: Text)` is a design sketch for a Form-compatible component. Workout, kitchen and focus apps supply their own limits and localization. Its demo shows 0:05 and 25:00, range endpoints, large text and VoiceOver adjustment. Theme may supply colors and typography; no Settings or session-engine dependency is required. Keep value validation and carry behavior explicit. The picker is not a timer. Apple documents [Picker](https://developer.apple.com/documentation/swiftui/picker), [Stepper](https://developer.apple.com/documentation/swiftui/stepper) and [UIDatePicker countdown](https://developer.apple.com/documentation/uikit/uidatepicker/countdownduration) (A). [PZCircularControl](https://github.com/philptr/PZCircularControl) provides editable circular controls (MIT, B), a different interaction with more accessibility and precision work; use native wheels for the first design.
