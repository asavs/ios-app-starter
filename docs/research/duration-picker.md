# Duration picker

Checked 2026-10-27. A: Apple. Recommendation: start with two labeled native SwiftUI wheel pickers for minutes and seconds, backed by one validated duration; use a Stepper for bounded small ranges if it better fits the workflow. `UIDatePicker` countdown mode displays hours and minutes, not seconds, even though its value is measured in seconds ([Apple, A](https://developer.apple.com/documentation/uikit/uidatepicker/countdownduration)). SwiftUI's date picker represents dates, so do not model an interval as a date merely for convenience. Define minimum, maximum and zero behavior and handle carry, localization, plural units and Dynamic Type. Expose distinct accessible labels and values, test VoiceOver adjustment and touch targets on iPhone and iPad. Native picker and Stepper APIs support iOS 17. Extract a reusable picker only after another app needs the same range and interaction.

The Maestro project reports that some wheel picker styles expose incomplete accessibility hierarchies, so test actual picker-wheel queries rather than assuming modifier placement ([Maestro, B](https://docs.maestro.dev/get-started/supported-platform/ios/swiftui)). This is a tool-specific report, not a general SwiftUI contract.
