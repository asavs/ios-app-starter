# Background audio cues

Checked 2026-10-27. A: Apple policy, documentation or DTS; B: developer report. Recommendation: keep cue policy in Val Time. Do not make silent audio a starter default.

Apple permits background services only for intended purposes under [review guideline 2.5.4, A](https://developer.apple.com/app-store/review/guidelines/). A silent loop used solely to keep a timer process alive risks rejection; the guideline does not explicitly decide every silent-buffer case, and review outcome cannot be predicted. Apple DTS says apps are typically suspended in the background, recommends scheduled local notifications for a timer and warns of background-mode scrutiny ([DTS, A](https://developer.apple.com/forums/thread/132078)). Debugger attachment changes suspension behavior, so test from the Home Screen on a locked phone without Xcode attached. No claim here establishes that the current Val Time implementation was rejected or tested.

Schedule local notifications in advance for meaningful phase events when permission is granted, reconcile and cancel them on pause/edit/end, and handle denied authorization. Notifications are system-delivered alerts, not a general way to run speech or code on schedule. They have user-facing presentation and scheduling limits, so test long sessions and notification settings rather than promising every 3-second cue. `BGTaskScheduler` is system-scheduled background work, not a precise timer ([Apple, A](https://developer.apple.com/documentation/backgroundtasks)). A Live Activity displays session state but is not a continuous execution grant ([ActivityKit, A](https://developer.apple.com/documentation/activitykit)). AlarmKit supports prominent user-authorized alarms and countdowns on iOS 26+, overriding Focus and silent mode; it is not a drop-in quiet cue mechanism ([WWDC25, A](https://developer.apple.com/videos/play/wwdc2025/230/)). Offer an iOS 17 notification fallback.

For legitimate foreground audio, AVAudioEngine can schedule generated PCM buffers; configure the audio session deliberately. `.mixWithOthers` enables mixing, while ducking is a separate choice. The playback category affects the silent switch and lock-screen behavior, and background mode should be used for genuine playback, not assumed timing entitlement ([audio session, A](https://developer.apple.com/documentation/avfaudio/avaudiosession), [mix option, A](https://developer.apple.com/documentation/avfaudio/avaudiosession/categoryoptions-swift.struct/mixwithothers)). Activate when needed, handle interruption, route changes and media-services reset, and test music, Bluetooth, lock, denial, and interruptions on device. Preserve user expectations and do not silently claim guaranteed background speech.

Apple?s archived `UILocalNotification` documentation describes a 64-pending limit for that deprecated API ([Apple, A](https://developer.apple.com/documentation/uikit/uilocalnotification)); it does not establish the current `UNUserNotificationCenter` limit. Measure actual behavior and handle scheduling errors on supported runtimes. Apple also documents checking notification authorization and settings before scheduling ([Apple, A](https://developer.apple.com/documentation/usernotifications/asking-permission-to-use-notifications)).
