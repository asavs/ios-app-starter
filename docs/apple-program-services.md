# Apple Developer Program services for the starter

Research checked against Apple documentation on 2026-11-08. The Apple Developer Program costs [US$99 per membership year](https://developer.apple.com/help/account/membership/program-enrollment/), with local pricing where available. The recommendations below are proposals for the relevant roadmap work, not a decision to enable services or change an account.

| Service | What Apple provides and constraints | Recommendation |
| --- | --- | --- |
| TestFlight | Membership includes TestFlight. Builds expire after 90 days; up to 100 internal and 10,000 external testers can be invited, and external testing requires beta review. [Apple's overview](https://developer.apple.com/testflight/) | Keep the existing GitHub delivery path as the default. It already delivers the demo to TestFlight. |
| Xcode Cloud | Membership includes 25 **compute** hours per month; parallel tasks consume usage separately from elapsed time. Additional plans are available. Initial setup requires Xcode, an app record and a connected repository; Apple warns generated projects may fail configuration or builds. [Hours](https://developer.apple.com/news/?id=ik9z4ll6), [usage](https://developer.apple.com/documentation/xcode/reviewing-xcode-cloud-usage-data), [setup requirements](https://developer.apple.com/documentation/xcode/setting-up-your-project-to-use-xcode-cloud) | Keep GitHub Actions as the default: the starter already builds and delivers there from Windows, and generates its project. Evaluate Xcode Cloud as an optional alternative only after proving setup without a separately managed Mac and measuring its usage. |
| CloudKit | CloudKit provides public, private and shared databases. Public data counts against the app container's quota; private data counts against the user's iCloud quota. Private access and public writes require an iCloud account. [Containers and quotas](https://developer.apple.com/documentation/cloudkit/ckcontainer) | Keep the current local database default. Consider optional sync when a real app needs it, with account, offline, conflict, schema migration and quota handling. Check current container limits in Apple's dashboard before promising capacity; no numerical allowance is asserted here. |
| Background Assets | The framework can download content from a developer's server or CDN. Managed Background Assets require iOS 26 or later; Apple hosting is available for App Store and TestFlight distribution, with up to 200 GB of compressed assets. [Overview](https://developer.apple.com/help/app-store-connect/manage-asset-packs/overview-of-apple-hosted-asset-packs), [asset packs](https://developer.apple.com/documentation/backgroundassets/creating-managed-asset-packs) | Leave off by default. Consider an optional module for an app with large downloadable content, including a plan for the starter's iOS 17 minimum and unavailable assets. |
| WeatherKit | Membership includes up to 500,000 API calls per month per membership, with paid plans for more. It requires an enabled App ID capability and attribution. [Pricing and requirements](https://developer.apple.com/weatherkit/), [App ID setup](https://developer.apple.com/help/account/services/weatherkit/) | Leave off by default. Add only for an app that needs weather, with usage monitoring, attribution and a failure state. |
| Foundation Models | Apple's on-device model runs offline, without an API key or per-request charge. The framework debuted on iOS 26; availability depends on Apple Intelligence support, settings, region and model readiness. [Apple's overview](https://developer.apple.com/foundation-models-framework/), [availability](https://developer.apple.com/documentation/foundationmodels/generating-content-and-performing-tasks-with-foundation-models), [on-device cost](https://developer.apple.com/videos/play/wwdc2025/360/) | Recommend an optional on-device adapter in the AI milestone, subject to the provider design and owner sign-off. Keep the base app and iOS 17 builds usable without it. Check OS and model availability at runtime, offer a useful unavailable state, and use a fake in automated UI tests. Never silently send local prompts to a cloud provider; make any cloud choice and data transfer clear to the person using the app. Evaluate model quality, context limits and changes across OS versions with real devices and representative prompts. |
| Small Business Program | Eligible developers must enroll; Apple describes a 15% commission on paid apps and in-app purchases, with eligibility based on proceeds of up to US$1 million, including associated accounts, and other terms. Rates and terms can vary by agreement and region. [Eligibility and enrollment](https://developer.apple.com/app-store/small-business-program/) | Document as an owner business decision when relevant. Do not enroll or accept agreements automatically. |

Apple also describes access to Foundation Models on Private Cloud Compute with no cloud API cost for developers enrolled in the Small Business Program with fewer than two million first-time App Store downloads. [Apple's framework page](https://developer.apple.com/foundation-models-framework/) states those conditions. This is a cloud service, distinct from the on-device model; confirm current eligibility, availability, terms, limits and privacy behavior before considering it as a separate optional provider. The AI adapter design should compare it alongside other providers rather than assume that the $99 membership alone grants access.
